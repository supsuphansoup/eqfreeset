# EQ FreeSet — A/B 블라인드 테스트 기반 개인화 EQ 웹서비스

이 프로젝트는 AutoEq 기반의 기기별 기본 보정 데이터를 출발점으로 하여, 브라우저 내 A/B 청취 비교를 통해 초보자도 쉽게 개인화된 10-band 이퀄라이저(EQ) 설정을 찾을 수 있도록 돕는 모바일 우선 반응형 웹서비스입니다.

오디오 처리와 개인화 탐색은 브라우저에서 실행하며 로컬 음원 파일을 서버에 업로드하지 않습니다.

---

## 주요 기능 및 스펙

### 1. 플랫폼 및 UX
- **모바일 우선 반응형 웹**: 모바일 화면(320px ~ 414px)에 최적화되어 있으며 데스크톱 브라우저에서도 원활하게 작동합니다.
- **PWA (Progressive Web App)**: 홈 화면 추가 및 모바일 앱처럼 설치하여 사용이 가능합니다.
- **다국어 지원**: 한국어, 영어, 일본어, 중국어 4개 국어를 지원합니다.
- **기본 다크 모드**: 시각적 피로를 줄이기 위한 정제된 미니멀리즘 다크 테마를 기본으로 사용합니다.

### 2. AutoEq 기반 기기 표준 DB
- 약 100종의 대중적인 블루투스 이어폰 및 헤드폰(Apple, Samsung, Sony, Bose, Sennheiser, JBL, Beats 등)의 기본 보정 데이터를 내장하고 있습니다.
- 모델명 alias 설계를 적용하여 간편한 검색을 지원합니다.
- 미지원 기기 요청 시 개발자에게 피드백을 보낼 수 있는 접수 흐름을 제공합니다.

### 3. 클라이언트 사이드 오디오 엔진
- **Web Audio API**: A/B의 같은 구간을 10밴드 필터로 사전 렌더링하고 모든 채널의 RMS를 맞춰 비교합니다. 샘플 피크는 −1 dBFS 이하로 감쇄하며 재청취는 캐시한 PCM을 사용합니다. 지각 음량 일치나 true-peak 제한을 보장하지는 않습니다.
- **자동 구간 분석 (2차 대역통과 필터)**:
  - 100% 브라우저 로컬 환경에서 디코딩된 PCM 오디오 데이터를 분석합니다.
  - 4개 음역대 축(저음, 온기, 보컬, 밝기)에 맞춰 대역통과 필터를 적용하며 스테레오 채널별 에너지를 합산합니다. 역상 신호를 모노 평균으로 상쇄하지 않습니다.
  - 구간별 실시간 RMS 에너지를 산출하여, EQ 차이가 가장 두드러지게 표현되는 대역별 에너지 점수와 구간 다양성을 기준으로 비교 후보군을 추출합니다.
- **오디오 입력 방식**: 10종의 고음질 정적 장르 샘플(팝, 힙합, 재즈, 클래식, EDM, R&B, 발라드, 인디, J-Pop, 락)을 제공하며, 사용자 로컬 음원 파일(MP3, WAV, M4A, FLAC 등) 업로드도 지원합니다. 모든 분석과 재생은 브라우저 내에서만 진행되어 오디오 파일을 서버로 전송하지 않습니다.

### 4. 적응형 취향 탐색 알고리즘
- **4가지 청각 인지 축**: 10밴드 EQ를 4개의 직관적인 청각 자극 축으로 그룹화하여 효율적으로 탐색합니다.
  - `bass` (저음 강도): 32Hz, 64Hz
  - `warmth` (온기감): 125Hz, 250Hz
  - `vocal` (보컬 명료도): 500Hz, 1000Hz
  - `brightness` (고음 밝기): 2000Hz, 4000Hz, 8000Hz, 16000Hz
- **격자 분포 탐색**: 기기별 허용 범위를 0.25 dB 이하 간격으로 나누고 선택별 우도로 가중치를 갱신합니다. 응답 오류를 허용하는 하한을 두며, 결과는 0.5 dB 단위로 제안합니다. 단일 선호 gain과 대칭 거리라는 가정은 실제 청취 실험으로 검증하지 않았습니다.
- **축별 비교 기회 배분**: 시도 횟수가 적은 축을 우선하고 동률이면 분포 폭이 큰 축을 선택합니다. 기본 16회, 8회씩 추가해 최대 32회입니다. A/B 배치는 무작위이며 ‘판단 어려움’은 추정에 반영하지 않습니다.
- **선택 취소**: 직전 응답을 제거하고 분포를 재계산해 당시 후보·구간으로 돌아갑니다.
- **최종 재청취**: 기기 기본 EQ와 전체 추천 EQ를 이름을 가린 상태로 비교한 후 선택한 값을 저장합니다. 기본 EQ를 선택하면 개인 보정은 적용하지 않습니다. 확인 전에는 결과를 저장하지 않습니다.
- **프리앰프 보정**: 겹치는 필터의 합산 주파수 응답을 계산해 감쇄합니다. 피크 리미터나 지각 음량 일치를 보장하지는 않습니다.
- **기기별 후보 범위**: 축의 모든 밴드가 기본값+델타 ±10 dB 안에 들어오도록 제한합니다. 이전의 약 ±6.37 dB 이동 한계를 개선했으며, 가상 응답 비교 결과와 한계는 [알고리즘 검토](ALGORITHM.md)에 기록했습니다.

### 5. 결과 확인 및 공유
- **인사이트 제공**: 선택한 취향 델타값에 맞춰 개별 맞춤 사운드 특성 요약 메시지를 표시합니다.
- **10-band EQ 시각화**: 0dB 기준선 대비 주파수별 변경치를 나타내는 미니멀한 바 그래프와 10개 밴드별 세부 dB 수치를 표시합니다.
- **JSON 다운로드**: 설정 값, Q/S, 프리앰프, 기준 샘플레이트를 포함한 JSON을 보관할 수 있습니다. 앱별 가져오기 호환성은 별도로 확인해야 합니다.
- **결과 공유**: `html2canvas`를 통해 결과 화면을 이미지 파일로 바로 저장하고, 최종 설정의 스냅샷을 담은 `/result/#eq=...` 링크를 복사해 다른 브라우저에서도 공유할 수 있습니다.

### 6. 데이터 영속성
- **로컬 저장소**: 최종 확인을 마친 테스트 결과는 브라우저 `localStorage['eqfreeset.results']`에 최대 50개까지 자동 누적 저장됩니다.
- **저장 실패 복구**: 용량 부족 등으로 저장하지 못해도 현재 결과를 표시하고 JSON 백업·재저장을 제공합니다. 저장 전 새로고침하면 결과가 사라질 수 있습니다.
- **결과 스냅샷**: 새 기록은 스키마·알고리즘·기기 버전과 기본/최종 EQ를 저장합니다. 기기 DB 변경 후에도 최종값을 유지합니다. 이전 기록은 스냅샷이 없어 현재 DB로 복원합니다.
- **결과 복원**: `/result?id={uuid}` 형식의 고유 주소로 접근하면 같은 브라우저에 남아 있는 델타 값과 테스트 로그를 불러올 수 있습니다. 저장 기록이 없는 ID는 다른 결과로 대체하지 않습니다.

## 서비스 구조 및 파일 구성

### 페이지 및 경로 (App Router)
- `/`: 서비스 소개, 작동 원리 3단계 요약, FAQ, 문의 및 법무 링크가 포함된 랜딩 홈
- `/test`: 기기 선택 → 음원 선택 → 구간 선택 → 기본 16회 A/B 테스트 → 최종 재청취·저장 화면
- `/result`: 최종 EQ 그래프 시각화, 상세 분석 수치, JSON 다운로드, 결과 공유 페이지
- `/info`: EQ 및 헤드폰 튜닝의 기초 원리 설명 페이지
- `/guide`: 청력 건강, EQ 프리셋 등 음향 관련 정적 정보 가이드
- `/contact`: Formspree API를 연동하여 기기 추가 요청이나 개선 사항 제보를 받는 이메일 피드백 창
- `/terms` / `/privacy` / `/license`: 이용약관, 개인정보처리방침, AutoEq 오픈소스 라이선스 고지 페이지

### 핵심 소스 파일 구성
- `src/lib/audio-store.ts`: Zustand 상태, 스테레오 구간 분석, 취향 탐색·재청취·선택 취소, 결과 저장
- `src/lib/preference-search.ts`: 가정한 응답 우도를 사용하는 격자 탐색과 후보 생성
- `src/lib/comparison-audio.ts`: A/B 사전 렌더링, RMS/샘플 피크 감쇄, 재청취 캐시
- `src/lib/device-db.ts`: AutoEq 데이터를 기반으로 하는 약 100종의 헤드폰 기본 보정 프리셋 및 별칭(alias) 검색 함수
- `src/components/bottom-nav.tsx`: 메인 화면 하단 탭 내비게이션 바 (테스트 및 결과 화면에서는 인터랙션 집중을 위해 숨김 처리)
- `src/app/globals.css`: Tailwind CSS v3 디렉티브 및 HSL 기반의 Refined Minimalism 디자인 시스템 토큰 정의
- `src/locales/`: 4개 국어(ko, en, ja, zh) 번역 데이터 보관소

## 개발 검증과 정확성 검토

Node.js 20.19 이상이 필요합니다. Next.js 16.4.6·React 19.3.1을 사용하며 `npm ci`로 잠금 파일에 맞춰 설치합니다. 정적 출력은 `out/`입니다. `npm start`는 정적 배포 미리보기 용도가 아니므로 `python tests/serve-static.py` 또는 정적 호스팅으로 확인하세요.

```sh
npm run lint
npm run build
npm test
npm run test:e2e
npm audit
npm audit --omit=dev
```

브라우저 테스트 최초 실행 전 `npx playwright install chromium`이 필요합니다. E2E 테스트는 `npm run build`로 만든 `out/`을 사용하며 Python 3 정적 서버를 로컬에서 실행합니다.

현재 탐색식의 의미, 기기 데이터 출처 검증, 음량 매칭과 보안 업데이트 등 남은 과제는 [알고리즘과 정확성 검토](ALGORITHM.md)를 참고하세요.
