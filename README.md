# EQ FreeSet — A/B 블라인드 테스트 기반 개인화 EQ 웹서비스

이 프로젝트는 AutoEq 기반의 기기별 기본 보정 데이터를 출발점으로 하여, 브라우저 내 A/B 청취 비교를 통해 초보자도 쉽게 개인화된 10-band 이퀄라이저(EQ) 설정을 찾을 수 있도록 돕는 모바일 우선 반응형 웹서비스입니다.

모든 오디오 처리 및 개인화 탐색 알고리즘은 서버 전송 없이 **100% 클라이언트(브라우저) 내에서 안전하게 동작**합니다.

---

## 주요 기능 및 스펙

### 1. 플랫폼 및 UX
- **모바일 우선 반응형 웹**: 모바일 화면(320px ~ 414px)에 최적화되어 있으며 데스크톱 브라우저에서도 원활하게 작동합니다.
- **PWA (Progressive Web App)**: 홈 화면 추가 및 모바일 앱처럼 설치하여 사용이 가능합니다.
- **다국어 지원**: 한국어, 영어, 일본어, 중국어 4개 국어를 지원합니다.
- **기본 다크 모드**: 시각적 피로를 줄이기 위한 정제된 미니멀리즘 다크 테마를 기본으로 사용합니다.

### 2. AutoEq 기반 기기 표준 DB
- 약 100종의 대중적인 블루투스 이어폰 및 헤드폰(Apple, Samsung, Sony, Bose, Sennheiser, JBL, Beats 등)의 기본 보정 데이터를 내장하고 있습니다.
- 모델명 alias 설계를 적용하여 간편한 검색을 지원합니다.
- 미지원 기기 요청 시 개발자에게 피드백을 보낼 수 있는 접수 흐름을 제공합니다.

### 3. 클라이언트 사이드 오디오 엔진
- **Web Audio API**: 브라우저 내에서 BiquadFilterNode 체인(10밴드)과 GainNode를 연동하여 지연 없는 실시간 EQ 및 A/B 오디오 전환을 구현합니다.
- **자동 구간 분석 (Butterworth 필터 시뮬레이션)**:
  - 100% 브라우저 로컬 환경에서 디코딩된 PCM 오디오 데이터를 분석합니다.
  - 4개 음역대 축(저음, 온기, 보컬, 밝기)의 대표 주파수 범위에 맞춰 Butterworth 대역통과 필터 계수(Bilinear Transform)를 계산하고 적용합니다.
  - 구간별 실시간 RMS 에너지를 산출하여, EQ 차이가 가장 두드러지게 표현되는 최적의 겹치지 않는 top-3 구간을 추출합니다.
- **오디오 입력 방식**: 10종의 고음질 정적 장르 샘플(팝, 힙합, 재즈, 클래식, EDM, R&B, 발라드, 인디, J-Pop, 락)을 제공하며, 사용자 로컬 음원 파일(MP3, WAV, M4A, FLAC 등) 업로드도 지원합니다. 모든 분석과 재생은 브라우저 내에서만 진행되어 개인 오디오 정보 유출 우려가 없습니다.

### 4. Bayesian 기반 개인화 탐색 알고리즘
- **4가지 청각 인지 축**: 10밴드 EQ를 4개의 직관적인 청각 자극 축으로 그룹화하여 효율적으로 탐색합니다.
  - `bass` (저음 강도): 32Hz, 64Hz
  - `warmth` (온기감): 125Hz, 250Hz
  - `vocal` (보컬 명료도): 500Hz, 1000Hz
  - `brightness` (고음 밝기): 2000Hz, 4000Hz, 8000Hz, 16000Hz
- **Bayesian Prior 및 업데이트**:
  - 초기 표준편차 `bayesStd = 5` (±5dB 탐색 범위)에서 시작합니다.
  - 매 라운드 선호도 선택 결과("A가 나음", "B가 나음", "비슷함")에 따라 Thurstone 근사 방식을 사용하여 축별 평균(`bayesMean`)과 표준편차(`bayesStd`)를 갱신합니다.
- **최대 정보 이득 축 선택**: 매 라운드 표준편차가 가장 큰 축(가장 불확실성이 높은 축)을 동적으로 선택하여 16라운드 안에 4개 축이 조화롭게 수렴되도록 합니다.
- **조기 종료 (Early Stop)**: 10라운드 이후 모든 축의 표준편차가 2.0 이하이고, 평균 표준편차가 1.5 이하로 수렴하면 테스트를 자동으로 조기 종료합니다.
- **Loudness Normalization (Preamp 보정)**: 더 큰 소리가 더 좋게 들리는 볼륨 착시를 방지하기 위해, 필터 적용 후 전체 평균 스펙트럼 파워에 비례해 메인 GainNode의 게인을 자동으로 감쇄합니다.
- **±10dB 3중 하드 클램핑**: 과도한 boost/cut으로 인한 왜곡 및 장비 손상을 막기 위해 Gain 계산, Bayesian 업데이트, 최종 출력 단계에서 최대 ±10dB로 엄격히 제한합니다.

### 5. 결과 확인 및 공유
- **인사이트 제공**: 수렴된 취향 델타값에 맞춰 개별 맞춤 사운드 특성 요약 메시지를 표시합니다.
- **10-band EQ 시각화**: 0dB 기준선 대비 주파수별 변경치를 나타내는 미니멀한 바 그래프와 10개 밴드별 세부 dB 수치를 표시합니다.
- **JSON 다운로드**: 설정 값을 JSON 형식 파일로 내려받아 보관할 수 있습니다.
- **결과 공유**: `html2canvas`를 통해 결과 화면을 이미지 파일로 바로 저장하고, 해당 결과 복원용 URL(UUID 쿼리)을 클립보드에 복사해 공유할 수 있습니다.

### 6. 데이터 영속성
- **로컬 저장소**: 완료된 테스트 결과는 브라우저 `localStorage['eqfreeset.results']`에 최대 50개까지 자동 누적 저장됩니다.
- **결과 복원**: `/result?id={uuid}` 형식의 고유 주소로 접근하면 이전의 델타 값과 테스트 로그를 언제든지 불러올 수 있습니다.

## 서비스 구조 및 파일 구성

### 페이지 및 경로 (App Router)
- `/`: 서비스 소개, 작동 원리 3단계 요약, FAQ, 문의 및 법무 링크가 포함된 랜딩 홈
- `/test`: 기기 선택 → 음원 선택 → 구간 선택 → 16라운드 A/B 테스트 통합 진행 화면
- `/result`: 최종 EQ 그래프 시각화, 상세 분석 수치, JSON 다운로드, 결과 공유 페이지
- `/info`: EQ 및 헤드폰 튜닝의 기초 원리 설명 페이지
- `/guide`: 청력 건강, EQ 프리셋 등 음향 관련 정적 정보 가이드
- `/contact`: Formspree API를 연동하여 기기 추가 요청이나 개선 사항 제보를 받는 이메일 피드백 창
- `/terms` / `/privacy` / `/license`: 이용약관, 개인정보처리방침, AutoEq 오픈소스 라이선스 고지 페이지

### 핵심 소스 파일 구성
- `src/lib/audio-store.ts`: Zustand 기반 상태 관리 스토어 및 오디오 핵심 프로세싱 (Web Audio API 제어, Butterworth RMS 세그먼트 분석, Bayesian 갱신 공식, 결과 누적 로직 포함)
- `src/lib/device-db.ts`: AutoEq 데이터를 기반으로 하는 약 100종의 헤드폰 기본 보정 프리셋 및 별칭(alias) 검색 함수
- `src/components/bottom-nav.tsx`: 메인 화면 하단 탭 내비게이션 바 (테스트 및 결과 화면에서는 인터랙션 집중을 위해 숨김 처리)
- `src/app/globals.css`: Tailwind CSS v3 디렉티브 및 HSL 기반의 Refined Minimalism 디자인 시스템 토큰 정의
- `src/locales/`: 4개 국어(ko, en, ja, zh) 번역 데이터 보관소
